# 今日老婆与同行玩法

命令：`#今日老婆`（也接受 `#回响今日老婆`）、`#回响同行收藏`、`#回响同行奖励`。
主菜单和玩法说明均有入口。

每日按北京时间划分。首次领取后，当天角色固定；跨群重复领取不会重抽。
本版抽取池包含已确认的 25 位女性角色，名单见 `lib/character-assets/roster.json`。
素材包中的其余头像也收录在素材库中，不自动加入抽取池。

领取角色后，成功完成下列每类玩法，当天首次增加亲密度 2 点：

- 十连补给
- 刮刮乐开票（逐格揭晓不重复计数）
- 福袋
- 派遣出发
- 领取派遣
- 档案答对（答错不计）
- 图鉴兑换

完成三类后，手动领取同行奖励：星屑 10 点、当日角色亲密度 5 点，每天一次。
首次相遇增加亲密度 1 点；亲密度、相遇天数与同行收藏跨天保留。
未领取今日角色时，原有玩法照常运行，不追溯当天已经完成的玩法。

每日页使用完整立绘，收藏页使用头像。自定义素材可放在 `assets/companions/<id>.png|webp|jpg`，
优先于内置素材。通过 `assets/companions/roster.json` 可配置自己的 `{id,name}` 名单，
该目录为本地数据，不随 Git 更新覆盖。

头像与立绘来自用户提供的 `wuwa_avatars.zip`、`wuwa_artwork.zip`，原角色和图片归原权利方。
`catalog.json` 保留用户提供的角色名称、角色 ID、头像来源链接及文件校验信息。
